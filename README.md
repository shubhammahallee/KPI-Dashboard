# 📊 CSV KPI Dashboard (Streamlit)

An interactive Streamlit web application that allows users to upload a CSV file and instantly generate **key performance indicators (KPIs)** and **visual insights** from numeric data.

---

## 🚀 Features

- Upload any CSV file
- Automatically detects numeric columns
- Select a column to analyze
- Displays key KPIs:
  - Total Sum
  - Average
  - Maximum
  - Minimum
- Interactive visualizations:
  - Line Chart
  - Bar Chart
  - Histogram (distribution)
- Clean UI with a custom background image

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit** – Web app framework
- **Pandas** – Data handling
- **Plotly Express** – Interactive charts
